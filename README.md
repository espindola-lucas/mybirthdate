# Cumple 🎂 — retro arcade

Sitio estático (HTML/CSS/JS), mobile-first. Sin build.

## Personalizar
Editá `js/config.js`: nombre, edad, fecha, lugar, mapa, qué llevar y tu WhatsApp (con código de país, sin `+`).

## Probar local
```bash
python3 -m http.server 8000
```
Abrí http://localhost:8000

## Publicar en GitHub Pages
1. Subí este directorio a un repo de GitHub.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Listo: `https://<usuario>.github.io/<repo>/`
